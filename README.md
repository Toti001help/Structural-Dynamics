# Structural Dynamics

Questa repository raccoglie una serie di script MATLAB sviluppati per l'analisi dinamica di strutture meccaniche e civili.  
Gli script affrontano temi quali l'identificazione modale, la risposta in frequenza e l'analisi di sistemi a più gradi di libertà.

## Contenuto della repository

| File                                   | Descrizione                                                                 |
|----------------------------------------|-----------------------------------------------------------------------------|
| `Circle_fit.m`                         | Script per il fitting di dati su una circonferenza, utile per l'analisi di risposta in frequenza. |
| `Circle_fit_commentato.m`              | Versione commentata di `Circle_fit.m` per una migliore comprensione del codice. |
| `Provo_autovalori_bar_mio.m`           | Calcolo degli autovalori per un sistema strutturale, probabilmente una trave. |
| `Provo_es_autovalori_ROD_commentato.m` | Esercizio commentato sul calcolo degli autovalori di un sistema strutturale. |
| `chat_gpt_FRF.m`                       | Script per l'analisi della Funzione di Risposta in Frequenza (FRF). |
| `esercizio_3msse_6molle.m`             | Modellazione di un sistema a 3 masse e 6 molle. |
| `esercizio_3msse_6molle_forma_polare.m`| Analisi del sistema a 3 masse e 6 molle in forma polare. |
